## 订阅、API、Claude Code 是三套账

在 console.anthropic.com 或 platform.claude.com 充钱，claude.ai 仍然是 Free。这两个是 API 平台，按 token 用量计费，和 Pro / Max 订阅分开记账。官方帮助中心写明，API 用量从不计入会员账单。

## 国内付款的三道墙和四条路径

支付通道：网页订阅只接受信用卡和借记卡，不收支付宝、微信。国内发行的卡，包括带双币标识的，常在 BIN 校验环节被拒。一张张换卡反复试，反而容易触发风控。

地区：中国大陆和香港不在 Anthropic 支持地区名单内，台湾在。人在不支持地区使用不在官方支持范围内，挂 VPN 改变不了这个状态，账号会不会受限由 Anthropic 判断。

风控：官方综合几个信号做判断，包括卡的归属地、账单地址、登录 IP 和账号年龄。同一张卡别人能用你不能用，属于常见情况。

| 方式 | 账号归谁 | 门槛 | 主要风险 |
| --- | --- | --- | --- |
| 外币卡官方付 | 自己 | 有能扣款成功的国际卡 | 国内卡大多被拒，反复失败触发风控 |
| App 内购 | 自己 | 其他地区 Apple ID 或 Google 账号，礼品卡充值 | 准备步骤多，价格按商店地区定，部分通道无质保 |
| 人民币代充 | 自己 | 会付人民币，账号已过 KYC | 平台条款差异大，封号不保 |
| 成品号 / 合租 | 卖家或多人共用 | 无 | 账号不在自己手里，随时可能被收回 |

虚拟卡的情况也不乐观。有代充方按自己的实测口径给出 2026 年成功率 15–20%，开卡费加手续费和汇率，首月成本常超过 $20 的官方价，连续失败还可能让账号被暂停。这组数字来自单一第三方，只能当参考，但方向和"反复换卡会被风控盯上"是一致的。

## KYC 与风控：下单前先确认账号状态

11 月初，多家代充方在公开说明里都加了同一条前置条件：Pro 和 Max 充值都要求账号已通过 KYC，没过的账号强充会被卡在验证页，卡单不退不换。官方没有发布过对应的公告，这属于代充方为降低卡单率自己设的门槛，但对下单结果的影响是实际的：账号没过验证，钱付了也开不通。

官方说明里，身份验证由 Persona 收集证件和人脸自拍，数据存在 Persona 侧，不用于训练模型。验证失败可以重试、换一种证件，用完次数后通过官方帮助表单联系。这一步第三方代办不了。

账号被停用的常见原因包括多人共用一个号、登录地区频繁跳变、付款被撤销、内容违反使用政策。几家代充方的条款里，封号都被排除在退款之外，差别只在"掉订阅是否补期"。代充开的会员不走你的卡，不会自动续费，到期回 Free，要继续用就再下一单。

## 代充要什么凭据：Org ID、验证码、Cookie 差别很大

前排文章大多只写一句"不要给密码"。密码只是其中一种凭据，真正决定风险的是对方拿到的东西能干什么。

| 凭据 | 能做什么 | 风险 | 事后能否收回 |
| --- | --- | --- | --- |
| Organization ID | 账号的一串标识字符，用来把订阅开到对应组织 | 低，不含登录权限 | 不需要收回 |
| 一次性验证码 | 客服在官方页面发起登录后，你邮箱收到的短时有效验证码 | 中，取决于对方是否当场用完 | 几分钟后自动失效 |
| Cookie | 等同于账号的会话控制权，可以以你的身份读写账号 | 高，不需要密码也不需要验证码 | 只能靠改密码、退出所有设备 |

Organization ID 在 claude.ai 的 Settings → Account 页面最下方，复制一串字符就行。这种模式全程不碰密码，是目前比较常见的一种交付方式。一次性验证码模式多一步登录动作，验证码本身短时有效，用完即废。Cookie 模式要格外小心：拿到 Cookie 的人可以绕过密码和二次验证直接进入账号，交付后是否真的清除，你无法验证。

任何索要账号密码或 API Key 的代充都该直接终止。密码等于账号所有权，API Key 等于 API 余额的钱包。已经给过 Cookie 的，事后在设置里退出所有设备并改密码。

## 充完还是 Free？按这个顺序排查

1. 先退出再重新登录 claude.ai，打开 Settings → Plan 看是否显示 Pro 或 Max 和到期日。页面缓存是"充完还是 Free"最常见的原因。
2. 到账后等 10–20 分钟再启动 Claude Code，给系统同步额度留点时间。
3. Claude Code 提示要充 API，或者出现 `Credit balance is too low`：在 Claude Code 里输入 `/login`，选 Claude 账号登录；再检查环境变量 `ANTHROPIC_API_KEY`。这个变量优先于订阅，有它在就会按 API 扣费。macOS 或 Linux 用 `unset ANTHROPIC_API_KEY`，PowerShell 用 `Remove-Item Env:ANTHROPIC_API_KEY`，同时删掉 `~/.zshrc`、`~/.bashrc` 里的 export 行，重开终端后用 `/status` 确认当前走的是订阅。
4. 登录项里找不到订阅账号：`/logout`，再 `claude update`，完全关闭终端重开，重新 `claude` 登录。
5. 出现 `5-hour limit reached` 或 `You've reached your weekly limit`：网页、桌面、手机、Claude Code 共用同一份额度，白天在网页聊得多，晚上写代码就更容易撞顶。等提示里的重置时间，或者在 Settings → Usage 看两条进度条。官方没有公布具体条数。
6. 想在上限之后继续用：Settings → Usage 开启 usage credits，按标准 API 价计费，可以设月上限和自动充值，费用与订阅费分开出账。Claude Code 里的命令是 `/usage-credits`。App 内订阅只能在网页版开启，而且要先把卡绑上。
7. 提示 `Due to unexpected capacity constraints`，或者 Claude Code 报 `529 Overloaded`：全体用户请求过多导致的临时情况，不是额度问题，等几分钟再试，或者在 Claude Code 里用 `/model` 换个模型继续。
8. 登录报错 `There was an error logging you in`：关掉 VPN，禁用扩展，清缓存和 Cookie；仍然不行就看 status.claude.com。

发票和账单在 Settings → Billing → Invoices 查看，同一张发票也会发到账单邮箱，主题是 "Your receipt from Anthropic"。已经开出的发票不能改，账单日也不能直接改，只能取消后在想要的日期重新订。
